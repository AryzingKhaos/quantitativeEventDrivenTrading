# 总体规划 · ROADMAP

> 这是**粗线条**的版本路线图，只定每个版本的**主要目标**，随时可能调整。
> 细节看各版本目录（`0.0.x/`）里的 README 与 step 文档。

## 北极星

**事件驱动的自动交易**：抓尽可能多会影响交易的消息（主攻 crypto 与 A股），消息对交易影响越大、分越高；最终由系统自动判断方向、量级并执行交易。

已锁定的大方向：

- **crypto 先做深**（24/7、数据与执行 API 现成），A股 渐进跟上。
- **最终全自动下单**，但分阶段走：先把"判断"做准，再用真实行情校准，再纸面验证，最后才碰真钱。
- 关键词只负责召回，**真正的打分交给 LLM 的"预期冲击"判断**，再用行情校准。

## 演进主线

```
感知（看得准） → 校准（用真实行情验证判断） → 验证（纸面跑策略） → 执行（自动下单 + 风控）
```

## 版本阶梯（主要目标，越往后越可能变）

| 版本 | 状态 | 主要目标（一句话） |
| --- | --- | --- |
| **0.0.1** | ✅ 已完成 | 跑通 MVP：抓取 → 关键词过滤 → Telegram 推送（仅 crypto 新闻）。 |
| **0.0.2** | ✅ 已完成 | 抓取稳定性 + LLM 精筛层；加聚类 / digest / 反馈 / 效果追踪等基建。 |
| **0.0.3** | ◀ 当前 | **消息质量**：打分从"关键词相关"改成"预期交易冲击"，crypto 信源做深 + A股 最小可用（cninfo）。不碰交易，但字段为终局预留。 |
| **0.0.4** | 规划中 | **行情闭环**：把 LLM 估的冲击校准成**实测涨跌**（超额收益 / MFE-MAE，事件交易视野）。crypto 先行，仍只出信号、人工决策。 |
| **0.0.5** | 设想 | **A股 做深**：接财联社 / 交易所公告 / 互动易，建板块·概念传导；双市场打分都用行情校准。 |
| **0.0.6** | 设想 | **策略与纸面交易**：从单条信号升级为策略，paper trading 跟踪虚拟 P&L，验证有效性。 |
| **0.0.7+** | 远期 | **自动执行 + 风控**：接交易所 / 券商 API，仓位管理、止损、合规。北极星落地。 |

0.0.4 及以后均为**暂定**，会随 0.0.3 的实际质量表现和数据反推调整。

## 贯穿各版本的原则

- **不重写，增量替换**：主干 `collect → normalize → filter → refine → cluster → notify` 一直保留，每版只在节点上加能力。
- **每步可灰度、可回滚、可观测**：改动带开关，"为什么推 / 不推 / 几分"全程可追。
- **为下一阶段预留接口**：当前版本不做的事，也把它需要的字段先记好（如 0.0.3 不交易，但先存 `tickers / direction / detect_latency`）。
- **真钱最后碰**：执行层放在信号质量与行情校验都过关之后。
