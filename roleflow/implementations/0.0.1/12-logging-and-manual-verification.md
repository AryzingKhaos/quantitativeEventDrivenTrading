# Step 12 - Logging And Manual Verification

## 目标

补齐第一版日志和人工验证闭环，确保可以稳定值守运行。

## 任务

1. 输出结构化日志
2. 记录每轮抓取统计
3. 记录推送成功和失败统计
4. 提供最小手工验证步骤
5. 整理上线前检查清单

## 每轮日志至少应包含

- 来源名称
- 抓取条数
- 新增条数
- 命中条数
- 推送条数
- 错误数

## 手工验证建议

1. 验证数据库连接
2. 验证单个 collector 输出
3. 验证去重逻辑
4. 验证评分逻辑
5. 验证 Telegram 推送
6. 验证重试与告警

## 完成标准

- 可以快速判断某个来源是否失效
- 可以快速判断为什么某条消息被推送或未推送
- 项目达到第一版人工值守可运行状态

## 注意点

- 第一版先以可排查为目标
- 不提前引入复杂监控平台
