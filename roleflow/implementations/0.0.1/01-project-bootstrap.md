## 任务

1. 初始化 `package.json`
2. 配置 TypeScript
3. 建立 `src/` 主目录结构
4. 建立 `index.ts` 和 `bootstrap.ts`
5. 配置基础脚本，例如 `dev`、`build`、`start`

## 建议产物

- 先不实现业务逻辑
- 先确保骨架稳定和可扩展
