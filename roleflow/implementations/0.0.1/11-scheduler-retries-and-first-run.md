# Step 11 - Scheduler, Retries And First Run

## 目标

实现调度、单数据源重试、首次启动历史候选处理。

## 任务

1. 用 `node-cron` 注册轮询任务
2. 按 `pollIntervalSec` 调度不同来源
3. 单个来源抓取失败时立即重试
4. 单个来源最多重试 `3` 次
5. 超过 `3` 次后发送 Telegram 告警
6. 判定是否为首次启动
7. 首次启动时每个来源抓最近 `20` 条候选
8. 对候选集评分后仅推送前 `10` 条

## 首次启动判定

- 当 `events` 表为空时，视为首次启动

## 完成标准

- 定时任务可按来源分别执行
- 单源失败不会阻塞全部流程
- 首次启动不会刷屏

## 注意点

- 尽量串行抓取或轻量错峰
- 第一版不引入任务队列
